# RA2 clone

Independent C# reimplementation of Red Alert 2 / Yuri's Revenge for learning.
Requires your own legally owned copy of the game; no original assets or binaries are included.

Layout: see `docs/`. Workflow: research -> spec -> implement -> test -> review (see `.github/copilot-instructions.md`).

`.gitignore` must contain: `refs/`, `*.mix`, `*.exe`, `*.dll` (game files), analysis dumps.
